# なかとも（デモ版）

子どもの見守りアプリです。子どもが小さな**タグ**を持ち、家・学校・通学路などに置いた**ノード**がタグを見かけると、**信頼できる人の輪**（保護者・家族・先生・友達の家族）に知らせます。推し活SNS「ともはね」とは別のアプリです。

> **デモ版です。** にせのタグとノードで動きます。ログインはなく、画面の上のボタンで「だれとして見るか」を切りかえます。**実際の子どもには使いません。** データはメモリの中だけで、再起動すると最初にもどります。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3200
npm test         # 見守りの判定とAPIのテスト
```

右側の「シミュレーター」で、タグを歩かせたり、こまったことを起こしたりできます（デモの日は 2026年11月4日・水曜日）。

## アラーム

| アラーム | どう気づくか | キャラ |
| --- | --- | --- |
| 消えた | 通学・帰宅の時間帯の中で、15分どのノードにも見えない | 🐾 モグ（先に、次に通るはずのノードがこわれていないか確かめる。こわれていれば「故障のお知らせ」にする） |
| 着いていない | 時間帯やピンポイントの「着く約束」の時刻をすぎても、行き先で見かけていない | 🐾 モグ |
| いつもとちがう道 | 「通る約束」のノードを通らなかった（お知らせ） | 🐱 ヤマネコ |
| 入らない場所 | 家族が決めた場所（線路わきなど）のノードで見かけた。**いつでも**鳴る | 🦉 フクロウ |
| SOS | 子どもがタグの SOS ボタンを押した。**いつでも・全員に** | 🐕 シバ |

- **だんだん強く**：保護者 → 5分だれも見なければ家族にも → 10分で「110番の準備」（警察に伝えることのメモ）。SOS はすぐ全員・すぐ110番の準備。入らない場所はすぐ家族にも
- **電話をかけるのは保護者**。キャラは準備と知らせまで
- 🐱 ヤマネコが「最後に見かけた場所と時刻」を、🐕 シバが「次にやること」を出す
- 子どものタグのボタン：**だいじょうぶ**（アラームを取り消す）／**遅くなる**（2回押し。今日の時間帯を30分のばす）

## 約束（保護者が決める）

- **時間帯**：曜日ごとの通学・帰宅（例：水曜は 14:00〜15:00 におばあちゃんの家へ）。時間帯には15分の余裕
- **ピンポイント**：着く・通る・入らない。今日だけの約束もできる。1日5つまで（多すぎると、まちがいのアラームが増える）
- **見守らない日**：土日と、保護者が決めた日。見守らない日も、SOS と入らない場所だけは見る
- ピンポイントにできるのはノードがある場所だけ。大事な場所には、古いスマホやラズパイでノードを置く

## 見守りの輪

保護者が招待コードを作り、招待された人は「見えること・見えないこと」を読んで同意してから入ります。コードは1回だけ。いつでも抜けられます。

| 役割 | 見えること | 見えないこと |
| --- | --- | --- |
| 保護者 | すべて（約束を決める・招待する） | ― |
| 家族・親戚 | 保護者が気づかないときのアラーム・SOS・危険 | 約束の設定を変えること |
| 先生 | 学校の時間だけ：学校に着いた／まだ着いていない・SOS | 学校の外での動き |
| 友達の家族 | タグを中継する・SOS が出たこと | 子どもがどこにいるか・だれのタグか |

子どもの画面には、シバが「あぶないときだけ知らせる」ことと、見守ってくれている人の一覧を出します。子ども同士は見守り役にしません。

## 守るしくみ

- タグには名前を入れない。番号だけで、番号は1時間ごとに変わる（拾った人が同じタグを追いかけられない）。番号が見えるのは保護者だけ
- 見かけた記録は「どのノードで、いつ」だけ。30日で自動的に消える
- 友達の家族には、場所も名前も出さない
